# tambat

Docker Compose setups for the backing services your app needs during development — one
command to start, the same behaviour on WSL2, Ubuntu, and macOS.

> **Status: pre-release.** v0.1 is still being built. The layout, the CLI, and the
> topologies can all change without notice, and there is no release to install yet.

> **Development only.** Default credentials, no TLS, no backups. Don't run it on a machine
> reachable from the internet, and don't point it at data you care about.
